A creative coding project I am interested in

Artist: Max Bittker

Max Bittker is an artist, designer, and creative coder based in New York. He creates interactive digital projects that allow people to explore, play, and create through the browser. His work often combines art, coding, simulation, and playful interaction. Instead of simply looking at a finished artwork, users can participate in the work and create their own experiences. One of his well-known projects is Sandspiel, a falling-sand simulation where users can draw with different materials and watch them interact. I like his work because he uses code not only as a technical tool, but also as a creative medium.

Creative Coding Project:Sandspiel

I am interested in Sandspiel, an interactive creative coding project. In Sandspiel, I can use my mouse to draw different elements, such as sand, water, fire, and plants. The elements then move and interact with each other based on the rules of the program. I like this project because I am not just drawing a static picture. My actions can create something that changes and develops over time. I think it is interesting how coding can be used to create an interactive form of art.
