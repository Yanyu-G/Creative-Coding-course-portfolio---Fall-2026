Sketch 1 — Forest Sketch 2 — Rabbit

Reflection

For this week's assignment, I created two separate HTML pages for my sketches and used links to switch between them. I am not sure if this is the best way to switch between sketches, but it works for my project. I would like to learn if there is a more efficient way to do this within one page.

For the rabbit animation, I drew each frame by myself and then used code to connect them into a looping animation. I also added keyboard interactions, allowing the rabbit to jump left or right when the user presses the arrow keys. When no key is pressed, the rabbit continues jumping in place. This process helped me understand how frame sequences and user interaction work together.

I am quite satisfied with the rabbit animation because I was able to turn my drawings into an interactive character. It was interesting to see how small changes between each frame could create movement.
