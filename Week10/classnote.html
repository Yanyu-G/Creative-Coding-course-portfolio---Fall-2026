Week 10 Class Note

Sound & Audio Synthesis

1. loadSound() - Loading Audio Files

Loads an existing audio file into p5.js.

We can use sound files such as MP3 or WAV.

preload() loads the sound before the program starts.

2. play() / stop() / loop() - Sound Playback

play() → Plays the sound.

stop() → Stops the sound.

loop() → Repeats the sound continuously.

Playing a sound multiple times may cause overlapping sounds.

3. mousePressed() - Mouse Interaction

Runs every time the mouse button is pressed.

We can use mouse clicks to play, stop, or change a sound.

4. onOff - Sound Toggle

A variable used to switch between two states.

onOff = 0 → Sound OFF

onOff = 1 → Sound ON

An if-else statement allows us to switch between these states.

5. rate() - Playback Speed

Changes how fast an audio file plays.

rate(1) → Normal speed

rate(2) → Double speed

rate(0.5) → Half speed

Changing playback speed also changes the pitch.

Negative rates may not work in newer library versions.

6. map() - Mouse-Controlled Sound

Converts a value from one range into another.

mouseX → Controls Sound 1 playback rate.

mouseY → Controls Sound 2 playback rate.

We can control multiple sounds by moving the mouse.

7. Reverb - Sound Effects

Reverb simulates sound reflections inside a physical space.

For example, sounds in a subway station or a large hall.

Dry Sound → Original sound without effects.

Wet Sound → Sound processed with effects.

Reverb makes sounds feel more spacious and atmospheric.

8. connect() / disconnect() - Audio Routing

Controls how audio signals travel through sound effects.

disconnect() → Removes an audio connection.

connect() → Connects audio to an effect.

Sound can pass through reverb, filters, or delay.

Class Note: Reverb had compatibility issues during class.

9. Audio Synthesis - Creating Sound

Generates sound electronically instead of playing an audio file.

We can create sounds by controlling waveforms.

Frequency, amplitude, and waveform affect how a sound is heard.

10. Oscillator - Generating Sound Waves

An oscillator generates a repeating waveform.

Different waveforms create different sound qualities.

Sine Wave → Smooth and pure sound.

Square Wave → Sharp electronic sound.

Triangle Wave → Soft sound.

Sawtooth Wave → Bright and rich sound.

11. Frequency - Sound Pitch

Frequency is the number of wave cycles per second.

It is measured in Hertz (Hz).

Higher Frequency → Higher pitch.

Lower Frequency → Lower pitch.

Fast repeating pulses can be heard as a continuous tone.

12. Amplitude - Sound Volume

Amplitude describes the strength of a sound wave.

Small Amplitude → Quieter sound.

Large Amplitude → Louder sound.

Amplitude = 0 → Silence.

13. start() / stop() - Oscillator Control

start() → Starts the oscillator.

stop() → Stops the oscillator.

Starting and stopping suddenly may create clicking sounds.

14. amp() - Amplitude Control

Controls the amplitude of an oscillator.

amp(0) → Silent.

amp(1) → High amplitude.

We can keep an oscillator running and change its amplitude.

Gradual changes create smoother sound transitions.

15. keyPressed() - Keyboard Interaction

Runs when a keyboard key is pressed.

We can press a key to start an oscillator.

Browsers usually require user interaction before playing audio.

16. console.log() - Debugging

Displays information in the browser console.

Helps us check if a function or if statement is working.

Useful when a sound does not play as expected.

Key Takeaways

Audio Playback → Plays existing sound files.

Audio Synthesis → Creates new sounds using oscillators.

Mouse and keyboard interactions can control playback speed, frequency, and amplitude.
